# Инструкция для тренеров

## Начало работы

### Регистрация
1. Откройте бота в Telegram
2. Отправьте команду `/coach` для регистрации в качестве тренера
3. После регистрации вы увидите главное меню с кнопками

## Главное меню

Главное меню тренера содержит следующие разделы:
- **📅 Управление расписанием** - создание и редактирование тренировок
- **💳 Управление абонементами** - управление абонементами учеников
- **👤 Личный кабинет** - просмотр информации о себе
- **👥 Мои ученики** - список всех учеников с их абонементами
- **📅 Календарь** - открытие календаря тренировок (WebApp)

## Управление расписанием

### Просмотр расписания
1. Нажмите **📅 Управление расписанием**
2. Выберите **📅 Мое расписание**
3. Выберите способ просмотра:
   - **📅 На конкретную дату** - введите дату в формате ДД.ММ.ГГГГ (например, 15.01.2026)
   - **📆 На период** - введите начальную и конечную дату через пробел (например, 15.01.2026 20.01.2026)

### Добавление тренировки
1. Нажмите **📅 Управление расписанием**
2. Выберите **➕ Добавить тренировку**
3. Следуйте инструкциям бота:
   - Выберите группу из списка
   - Введите дату тренировки в формате ДД.ММ.ГГГГ
   - Введите время начала в формате ЧЧ:ММ (например, 18:00)
   - Введите продолжительность в формате "X часов Y минут" или просто "X минут"
   - Введите описание/место тренировки (необязательно)
4. Подтвердите создание тренировки

**Примечание:** Вы можете отменить операцию на любом этапе, нажав кнопку **❌ Отмена**

### Редактирование тренировки
1. Нажмите **📅 Управление расписанием**
2. Выберите **✏️ Редактировать тренировку**
3. Введите дату тренировки, которую хотите отредактировать
4. Выберите тренировку из списка
5. Выберите, что хотите изменить:
   - Время
   - Место/описание
   - Группу
   - Дату
6. Введите новое значение
7. Подтвердите изменения

### Создание расписания из шаблонов
1. Нажмите **📅 Управление расписанием**
2. Выберите **📋 Создать из шаблонов**
3. Введите количество недель, на которое нужно создать расписание
4. Подтвердите создание

**Примечание:** Система автоматически создаст тренировки на основе активных шаблонов недельного расписания, начиная с ближайшего понедельника.

### Календарь тренировок
1. Нажмите **📅 Календарь** или отправьте команду `/schedule`
2. Откроется календарь в формате WebApp
3. В календаре вы можете:
   - Просматривать все тренировки (свои и других тренеров)
   - Открывать детали тренировки
   - Отмечать посещаемость для прошедших тренировок

## Отметка посещаемости

### Через календарь (WebApp)
1. Откройте календарь через кнопку **📅 Календарь**
2. Найдите прошедшую тренировку (тренировки, которые уже прошли, отображаются отдельно)
3. Откройте детали тренировки
4. Нажмите кнопку **Выбрать** для выбора учеников
5. Отметьте галочками учеников, которые посетили тренировку
6. Нажмите **Подтвердить посещение**
7. Система автоматически:
   - Отметит посещаемость
   - Спишет одно занятие из абонемента каждого ученика
   - Отправит уведомление ученику о списании занятия

**Важно:**
- Отметить посещаемость можно только для прошедших тренировок
- Отметить посещаемость может только тренер, который ведет эту тренировку
- Если посещаемость уже была отмечена, повторная отметка невозможна

## Управление абонементами

### Добавление абонемента
1. Нажмите **💳 Управление абонементами**
2. Выберите **➕ Добавить абонемент**
3. Выберите ученика из списка (введите номер или нажмите на имя)
4. Выберите тип абонемента:
   - **⛰️ Пробное занятие** - 1 занятие на 30 дней
   - **💪 Абонемент на 12 занятий (Несгораемый)** - 12 занятий без ограничения по времени
   - **⛏️ Абонемент на 16 занятий (30 дней)** - 16 занятий на 30 дней
5. Подтвердите добавление

**Примечание:** После добавления абонемента ученик получит уведомление в Telegram с информацией о зачисленном абонементе.

### Удаление абонемента
1. Нажмите **💳 Управление абонементами**
2. Выберите **🗑️ Удалить абонемент**
3. Выберите ученика из списка
4. Выберите абонемент для удаления
5. Подтвердите удаление

### Просмотр списка учеников
1. Нажмите **💳 Управление абонементами**
2. Выберите **👥 Список учеников с абонементами**

Или используйте кнопку **👥 Мои ученики** в главном меню.

Вы увидите список всех учеников с информацией об их активных абонементах:
- Количество оставшихся занятий
- Общее количество занятий
- Статус абонемента (активен/истек)
- Дата окончания действия

## Личный кабинет

1. Нажмите **👤 Личный кабинет**
2. Просмотрите информацию о себе:
   - Имя и фамилия
   - Роль (тренер)
   - Дата регистрации

## Полезные команды

- `/coach` - регистрация/переход в режим тренера
- `/schedule` - открытие календаря тренировок
- `/start` - возврат в главное меню

## Важные замечания

1. **Отмена операций:** На любом этапе выполнения операции вы можете нажать **❌ Отмена** для возврата в главное меню

2. **Формат даты:** Всегда используйте формат ДД.ММ.ГГГГ (например, 15.01.2026)

3. **Формат времени:** Используйте формат ЧЧ:ММ (например, 18:00)

4. **Уведомления ученикам:** 
   - При добавлении абонемента ученик автоматически получает уведомление
   - При отметке посещаемости ученик получает уведомление о списании занятия

5. **Просмотр всех тренировок:** Тренеры видят все тренировки в календаре, не только свои

6. **Повторная отметка посещаемости:** Невозможна - система предотвращает дублирование
